# MI / Climate

Локальная панель Mi Temperature Sensor: температура, влажность, оценка заряда и графики температуры, влажности и напряжения с масштабом 1 час, 6 часов, сутки и неделя. Тёмный минималистичный интерфейс без сборки и npm.

## Запуск

Нужны Python 3.10+, Bluetooth-адаптер и датчик рядом. На Linux Bluetooth должен быть включён, а служба BlueZ — запущена. Остановите GATT.py и другие программы, уже подключённые к датчику.

```sh
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
python server.py
```

Откройте http://localhost:8000. Сервер слушает `0.0.0.0`: с телефона в той же сети откройте `http://<IP компьютера>:8000`. MAC по умолчанию `A4:C1:38:CC:2D:CB`, характеристика и формат пакета взяты из `GATT.py`. Для изменения адреса или порта: `MI_MAC=... PORT=8080 python server.py`.

История сохраняется в `data/readings.sqlite3`, включая после перезапуска. Сбор идёт, пока работает сервер; браузер можно закрыть. При потере Bluetooth соединение повторяется через 10 секунд. Страница обновляется раз в 5 секунд. Свежесть показаний учитывает выбранный интервал: порог — не менее двух минут или интервал плюс минута. График показывает последнее реальное измерение в каждом временном интервале; минимум, максимум и среднее рассчитываются по исходным измерениям. Наведите курсор на точку для точного значения и времени.

Процент батареи — грубая линейная оценка: 2.1 V = 0%, 3.1 V = 100%, ограниченная диапазоном 0–100%. Это не измеренный заряд: напряжение зависит от нагрузки, температуры и типа батарейки. Рядом показывается фактическое напряжение.

Проверки: `python -m unittest discover -s tests`.

## Если датчик не находится после перезапуска

Если появляется `Device with address ... was not found`, но `bluetoothctl info A4:C1:38:CC:2D:CB` показывает `Connected: yes`, возможно, осталось старое соединение. Освободите только этот датчик:

```sh
bluetoothctl disconnect A4:C1:38:CC:2D:CB
```

Работающий сервер повторит подключение автоматически. Не запускайте одновременно `GATT.py` и сервер. Останавливайте сервер через Ctrl+C и дождитесь завершения: сервер теперь даёт Bluetooth время на корректное отключение. При принудительном завершении процесса такая очистка невозможна.

Кнопки под графиком переключают температуру, влажность и напряжение. Подсказка показывает исходное значение и время измерения при наведении, касании или выборе стрелками клавиатуры. На телефонах график увеличивается по высоте.

## Интервал получения данных

На странице доступны непрерывный режим и интервалы 1, 5, 10, 30 минут, 1 час и «Никогда (пауза)». Настройка общая для всех браузеров и сохраняется в SQLite. По умолчанию остаётся непрерывный режим. В интервальном режиме сервер сохраняет один валидный пакет, отключает Bluetooth и ждёт до следующего срока (от времени последнего полученного пакета). Подключение и ожидание уведомления могут добавить задержку. Изменение настройки применяется без перезапуска; во время подключения — после завершения текущей попытки. Это не настройка частоты внутренних измерений датчика. Плановая пауза отображается отдельно от ошибки соединения. После перезапуска первый замер выполняется сразу. Если уведомлений нет 30 секунд, сервер переподключается.

## Docker и автоматическая выкладка

Инструкция: [deploy/README.md](deploy/README.md). Docker Compose настроен на `192.168.1.102:8088`; В репозитории подготовлен GitHub Actions workflow для сборки, тестов и выкладки. Он заработает после установки и регистрации runner с меткой `mi-temp` на сервере; эта настройка пока не выполнена. История хранится в отдельном томе.

Дополнительно доступны «1 час» и «Никогда (пауза)». Пауза сохраняется после перезапуска, прекращает сбор и отменяет текущую попытку подключения; история остаётся доступной. Выбор другого интервала возобновляет сбор с нового замера.

Кнопки 1 ч / 6 ч / 24 ч / 7 д задают ширину временного окна графика. Историю можно перемещать перетаскиванием, горизонтальным жестом трекпада, Shift + колесом, стрелками под заголовком. «К текущему времени» возвращает живой график. При просмотре прошлого автообновление не сдвигает окно; статистика относится к выбранному окну, карточки — к последним измерениям.
